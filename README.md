## Descripción de la tarea

La tarea busca dar los primeros pasos para **ganar visibilidad en el mundo de la IA** y conectar con la comunidad de profesionales del sector. Tiene dos apartados:

### Apartado 1. Cuenta en GitHub y "Hola Mundo"

- Crear una cuenta en [GitHub](https://github.com).
- Crear un primer repositorio (este) con:
  - Un archivo `README.md` escrito en **Markdown** con una breve explicación de la tarea.
  - Un programa sencillo **"Hola Mundo" en Python**.

## Cómo ejecutar el programa

Necesitas tener instalado [Python 3](https://www.python.org/downloads/).

```bash
git clone https://github.com/<tu-usuario>/<nombre-del-repo>.git
cd <nombre-del-repo>
python hola_mundo.py
```

Salida esperada:

```
Hola Mundo
```
